# Example Project

A small sample project prepared to be uploaded to GitHub.

## Description

This is a minimal static web project demonstrating a basic structure:
- `index.html` — main page
- `style.css` — styles
- `script.js` — client-side logic
- `README.md` — this file

## Features

- Click button to display the current time.
- Footer showing the current year.
- Console log on page load for debugging.

## How to run

Just open `index.html` in your browser. No build step required.
